# Charlotte Shop Hub

Phone app for Belt Power Charlotte fabrication time.

## Make it live on phones

1. Open https://github.com/Delirioustub/charlotte-shop-hub
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: main / folder: / (root)
5. Save and wait about a minute
6. Open https://delirioustub.github.io/charlotte-shop-hub/

On iPhone Safari: Share → Add to Home Screen.

Floor: sign in → type production order → tap step → stop → submit.
